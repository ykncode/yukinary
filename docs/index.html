UYGULAMA ALANLARI

Yukinary ile Neler Yapılabilir?

İşletim sistemi çekirdeğinden gerçek zamanlı yapay zeka çıkarımına kadar donanımın tüm gücünü elinize alın.

1. İşletim Sistemi & Kernel (YknOS)

Bare-Metal

Yukinary hiçbir harici C kütüphanesine veya libc'ye ihtiyaç duymadığı için doğrudan std/os/kernel.ykn, sayfalama (paging), kesmeler (IDT) ve donanım sürücüleri yazılabilir. YknOS mimarisi bu sayede saf Yukinary ile hayata geçirilebilir.

# YknOS Mikroçekirdek Giriş Noktası isv kernel_main(multiboot_ptr: *u8) -> tamsayi { vga_temizle(); vga_yaz("YknOS v0.1 Baslatildi! (Saf x86_64)\n".ptr); kesme_tablosu_kur(); dondu 0; }

2. Ultra Düşük Gecikmeli Ağ & Veritabanı

High Throughput

Standart kütüphanedeki yerleşik TCP/IP soketleri, HTTP/1.1 sunucu motoru, WebSocket ve B-Tree/WAL tabanlı gömülü SQL motoru ile saniyede yüz binlerce isteği mikrosaniyeler içinde karşılayabilirsiniz.

# Yukinary Yerel HTTP Sunucu Örneği ice_aktar std.web.sunucu; isv istek_isle(istek: *HttpIstek) -> *HttpYanit { dondu http_json_yanit(200, "{\"durum\":\"tamam\"}".ptr); }

3. Çevrimdışı Yapay Zeka Çıkarımı (BitNet)

AI Inference

Python, PyTorch veya gigabaytlarca bağımlılık olmadan; 1.58-bit BitNet ve GGUF modellerini doğrudan AVX2 SIMD makine talimatlarıyla saf CPU üzerinde çalıştırabilirsiniz.

# config { hedef: "pe32", llm: "bitnet" } isv akilli_analiz(giris: *u8) { degisken token: tamsayi = llm_gguf_transformer_token_uret(); sayiyi_ekrana_yaz(token); }

4. Sistem Araçları & Derleyiciler

1M lines/sec

Saniyede bir milyon satırdan fazla kod ayrıştırabilen mimarisiyle CLI yardımcı araçları, formatlayıcılar, statik analizciler ve oyun motoru alt sistemleri (ECS, glfw, wayland) geliştirmek için biçilmiş kaftandır.

# Bağımsız CLI Aracı Örneği isv ana() -> tamsayi { degisken arg: *u8 = komut_satiri_oku(1); ekrana_yaz("Dosya isleniyor: ".ptr); ekrana_yaz(arg); dondu 0; }
EVRENSEL KODLAMA

Kendi Dilinde Kod Yaz

Aynı program, 7 farklı dilde doğrudan derlenebilir. Aşağıdaki sekmelere tıklayarak sözdiziminin her dilde nasıl göründüğünü inceleyin.

🇹🇷 Türkçe Doğal Gramer x86_64 PE32+ / ELF64 Birebir Aynı Makine Kodu 
# Türkçe Doğal Sözdizimi
yapi Nokta {
    x: tamsayi;
    y: tamsayi;
}

isv fib(n: tamsayi) -> tamsayi {
    eger (n <= 1) ise {
        dondu n;
    }
    dondu fib(n - 1) + fib(n - 2);
}

isv ana() -> tamsayi {
    degisken p: Nokta;
    p.x = 10;
    p.y = 20;
    ekrana_yaz("Sonuc: ".ptr);
    sayiyi_ekrana_yaz(fib(7));
    ekrana_yaz("\n".ptr);
    dondu 0;
}

1. Kurulum ve Hızlı Başlangıç

Yukinary, geliştiricileri karmaşık derleyici toolchain'leriyle uğraştırmaz. Windows ve Linux için tek tıkla çalışan kurulum paketleri sunar.

Windows Turnkey Kurulumu

1. GitHub Releases sayfasından yukinary-setup-windows-x86_64.zip dosyasını indirin ve dışa aktarın.
2. Klasör içindeki setup.cmd dosyasına çift tıklayın.
3. Kurulum %USERPROFILE%\.yukinary\bin dizinine tüm binary'leri yerleştirir ve PATH ortam değişkenini otomatik yapılandırır.

Linux & macOS 1-Line Kurulumu

curl -fsSL https://raw.githubusercontent.com/ykncode/yukinary/main/setup.sh | bash source ~/.bashrc

Doğrulama ve İlk Test

ykn --version # Output: Yukinary v1.0.0 (x86_64-windows-pe32+ / elf64) ykn --yardim # Lists all subcommands, flags, and usage examples.

2. CLI Komut Referansı

ykn komut satırı arayüzü, geliştirme döngüsünün tüm ihtiyaçlarını karşılar:

Komut Açıklama Örnek Kullanım
ykn derle [dosya] Kaynak kodu doğrudan PE32+ (.exe) veya ELF64 ikili dosyasına derler. ykn derle ana.ykn -o program.exe
ykn calistir [dosya] Kodu derler ve bellekte anında çalıştırır. ykn calistir test.ykn
ykn convert [dosya] Python veya C kodlarını otomatik olarak Yukinary sözdizimine dönüştürür. ykn convert script.py --into-file script.ykn
ykn --self-heal [dosya] Kod üzerindeki sözdizimsel hataları otomatik onarır ve güvenlik denetimi yapar. ykn --self-heal bozuk.ykn
ykn --lsp VS Code ve diğer editörler için dahili Language Server Protocol sunucusunu başlatır. ykn --lsp

3. Hiyerarşik #config Orkestratörü

Yukinary'de derleme ayarlarını terminal bayraklarına yazmak zorunda kalmazsınız. Kaynak dosyasının başına koyacağınız #config bloğu, projenin derleme hedefini, optimizasyon seviyesini ve yapay zeka parametrelerini taşınabilir kılar:

# config { # hedef: "pe32", # optimize: 2, # llm: "bitnet", # llm_model: "models/bitnet-b1.58-2B-4T/ggml-model-i2_s.gguf", # bellek_guvenligi: "kati" # } isv ana() -> tamsayi { ekrana_yaz("Bu dosya kendi derleme parametrelerini tasir!\n".ptr); dondu 0; }

4. Hafıza Zabıtası & Güvenlik Modeli

Yukinary, çöp toplayıcı (Garbage Collector) içermez. Bunun yerine derleme zamanı Hafıza Zabıtası (Safety Gate) çalışır:

  • Use-After-Free (UAF) Koruması: Serbest bırakılan işaretçilerin yeniden okunması derleme anında tespit edilir ve engellenir.
  • Dizi ve Bellek Sınır Kontrolü: Statik aralık çıkarımıyla sınır aşımı (buffer overflow) riskleri elenir.
  • X-Ray Sandbox Gate: Yetkisiz sistem çağrıları sandbox seviyesinde kısıtlanabilir.

5. İşletim Sistemi Geliştirme (YknOS Mimarisi)

Yukinary ile bir işletim sistemi çekirdeği yazılabilir mi? Kesinlikle evet.

Çünkü Yukinary'nin hiçbir C çalışma zamanı (libc, msvcrt) bağımlılığı yoktur. Çıktı olarak ürettiği makine kodu doğrudan BIOS / UEFI bootloader tarafından 0x100000 adresine yüklenip icra edilebilir. std/os altında yer alan kesme yönetimi, sanal bellek (paging) ve VGA/Seri port sürücüleri YknOS'un yapı taşlarını oluşturur.

6. Kendi Dilini Ekle (Multi-Lingual Community Guide)

Yukinary topluluğu, dili dünyanın tüm dillerine açmayı taahhüt eder. Kendi ana dilinizi eklemek için 3 basit adım yeterlidir:

  1. tools/keyword_registry.json dosyasına dil kodunuzu (örn: "es") ve anahtar kelime eşlemelerini ekleyin.
  2. src/lexer.ykn içerisindeki anahtar kelime arama tablosuna kelimelerinizi tanımlayın.
  3. ykn derle src/main.ykn komutuyla derleyiciyi yeniden derleyin ve GitHub üzerinden Pull Request gönderin!
