## 1. 소개 및 설계 철학

**Yukinary (YKN)** 는 외부 C 런타임(libc/msvcrt), LLVM 및 타사 링커에 의존하지 않고 Windows(PE32+)와 Linux(ELF64)의 네이티브 기계어 코드를 직접 생성하는 독립형 셀프 호스팅 시스템 프로그래밍 언어입니다.

### 핵심 강점:
* **독립 네이티브 코드 생성:** 중간 파일 없이 AST에서 바로 최적화된 기계어 바이너리를 직접 생성합니다.
* **GC 없는 컴파일 타임 메모리 안전성:** 가비지 컬렉터 중단 없이 컴파일 타임에 포인터 생명주기와 Use-After-Free를 검증합니다.
* **한국어 키워드 직접 지원:** 한국어 키워드를 컴파일러 레벨에서 네이티브 문법으로 완벽히 해석합니다.
* **자가 치유 (Self-Healing) 기능:** 빠진 세미콜론, 철자 오류, 널 포인터 참조를 컴파일러가 스스로 감지하여 코드를 보호합니다.
* **16 KB 임베디드 AI 신경망:** BitNet 1.58b Ternary Transformer 모델이 컴파일러 내부에 탑재되어 0.1ms 속도로 동작합니다.

## 2. 설치 및 빠른 시작

./ykn_full hello.ykn -o hello

## 3. 다국어 네이티브 문법 시스템

Yukinary에서는 직관적인 한국어 키워드로 완벽한 시스템 코드를 작성할 수 있습니다:

```ykn
함수 합산하기(값: 정수) -> 정수 {
    변수 결과: 정수 = 값 * 2;
    만약 결과 > 100 이면 {
        반환 결과;
    } 그외 {
        반환 0;
    }
}
```

### 한국어 키워드 대응표:
* `함수` — 함수 선언
* `변수` — 변수 선언
* `만약` .. `이면` .. `그외` — 조건문
* `반복` — 반복문
* `반환` — 결과값 반환
* `구조체` — 사용자 정의 구조체
* `열거형` — 대수적 데이터 타입
* `일치` — 패턴 매칭
* `널` — 널 포인터 리터럴

## 4. 기본 타입, 변수 및 연산자

```ykn
변수 카운트: 정수 = 42;               # 64비트 정수 (i64)
변수 바이트값: 바이트 = 255;          # 8비트 부호 없는 정수 (u8)
변수 활성여부: 논리 = 참;             # 불리언 (참 / 거짓)
변수 원주율: 실수 = 3.14159;          # 64비트 부동소수점
변수 메시지: *바이트 = "안녕하세요 YKN!".ptr; # 바이트 포인터
```

논리 연산자:
* **그리고:** `그리고`, `and`, `ve`
* **또는:** `또는`, `or`, `veya`
* **아니다:** `아니다`, `not`, `degil`

## 5. 함수 및 제어 흐름

### 하드웨어 최적화 루프
반복문 카운터 변수는 CPU 레지스터(`RBX`, `R12`..`R15`)에 직접 할당되어 초고속으로 실행됩니다:

```ykn
함수 팩토리얼(n: 정수) -> 정수 {
    변수 결과: 정수 = 1;
    변수 i: 정수 = 1;
    반복 i <= n {
        결과 = 결과 * i;
        i = i + 1;
    }
    반환 결과;
}
```

## 7. 데이터를 담는 열거형 및 패턴 일치

```ykn
열거형 작업상태 {
    대기중,
    진행중(정수),    # 진행률(%) 데이터를 담음
    실패(정수),      # 에러 코드를 담음
    완료(정수)       # 결과 코드를 담음
}

함수 상태처리(s: 작업상태) -> 정수 {
    일치 s {
        작업상태.대기중 => {
            반환 0;
        }
        작업상태.진행중(진행률) => {
            반환 진행률;
        }
        작업상태.실패(에러코드) => {
            반환 0 - 에러코드;
        }
        작업상태.완료(결과코드) => {
            반환 결과코드;
        }
    }
}
```

## 9. 자가 치유 컴파일러 엔진 (Self-Healing)

`--onar` 또는 `--self-heal` 옵션을 사용하면:
1. 즉시 원본 코드의 `.bak` 스냅샷을 생성합니다.
2. 철자 오류를 고치고 누락된 `;`를 자동으로 삽입합니다.
3. 널 포인터 역참조 코드를 감지하여 보호 코드를 자동 주입합니다:
   ```ykn
   만약 포인터 != 널 이면 {
       반환 포인터.값;
   }
   반환 0;
   ```
4. 함수 종료 직전 누락된 `반환 0;`를 자동 보완합니다.
5. 복구된 코드는 컴파일 검증을 거친 후에만 최종 반영됩니다.

* 시스템 프로세스 실행 차단 (`CreateProcess`, `execve`)
* 외부 DLL/so 동적 라이브러리 탈취 차단

## 12. 내장 신경망: Micro-LLM

컴파일러 실행 파일 내부에 직접 내장된 **16 KB BitNet 1.58b Ternary Transformer**:
* GPU나 Python 없이 CPU에서 0.1ms 속도로 실시간 동작
* 문맥 기반 코드 자동 완성 및 진단 제안 제공
* `--llm-model model.gguf` 플래그로 대형 외부 GGUF 모델 연결 지원

## 14. 패키지 매니저 및 2개 저장소 구조

1. **컴파일러 코어 저장소:** `yukinary/yukinary`
2. **패키지 레지스트리 저장소:** `yukinary/packages`

`yukinary.toml`:
```toml
[package]
name = "my_app"
version = "0.1.0"
main = "main.ykn"
output = "build/app.exe"

[dependencies]
network = "1.0.0"
```

패키지 추가 명령:
```powershell
.\ykn_full.exe add network
.\ykn_full.exe build
```

## 15. 다국어 코드 변환 엔진 (`#convert`) 및 외부 FFI 연동

YKN은 초기 생태계 라이브러리 부족 문제를 해결하기 위해 두 가지 강력한 상호 운용성을 제공합니다:

### A. 제로 오버헤드 C-ABI FFI 연동 (`harici isv`)
C/C++ 또는 Rust로 컴파일된 공유 라이브러리(Windows `.dll`, Linux `.so`)를 즉시 호출할 수 있습니다:

```ykn
harici isv sqlite3_open(파일명: *바이트, db핸들: **바이트) -> 정수;
harici isv sqlite3_close(db핸들: *바이트) -> 정수;
```

### B. `#convert` 임베디드 코드 변환 지시어
YKN 소스 코드 내에 다른 언어의 코드를 직접 삽입하면 내장 변환기가 자동으로 YKN 코드로 트랜스파일합니다:
* `#C-convert` — C/C++ 함수와 구조체를 YKN으로 변환
* `#PY-convert` — Python 함수(`def`)를 정적 타입 YKN 함수로 변환
* `#JS-convert` — JavaScript 알고리즘 로직 변환

### C. 2단계 SHA-256 캐시 (`.ykn_cache/convert/`)
변환된 모든 코드는 SHA-256 해시로 안전하게 캐시되어 재컴파일 시 0ms 오버헤드로 즉시 빌드됩니다.
