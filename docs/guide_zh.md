## 1. 简介与核心架构理念

**Yukinary (YKN)** 是一门独立的、自举自编译（Self-Hosting）的系统级现代编程语言。它能够直接生成 Windows (PE32+) 和 Linux (ELF64) 纯本地原生机器码，完全无需依赖外部 C 运行时（libc/msvcrt）、LLVM 框架或第三方链接器。

### 核心亮点：
* **原生零依赖代码生成:** 从 AST 直接生成高效机器码，无需外部工具链。
* **无 GC 编译期内存安全:** 在编译期对所有权、借用检查与释放后使用（Use-After-Free）进行严格审查。
* **原生多语言语法支持:** 支持直接使用简体中文关键词编写系统代码。
* **自动化自愈机制 (Self-Healing):** 能够自动纠正拼写失误、补齐缺失分号及注入防崩溃的空指针守卫（Null-Guard）。
* **内置 16 KB 紧凑型 AI 模型:** 在二进制内部嵌入三值化（Ternary）BitNet 1.58b Transformer，0.1毫秒极速响应。

## 2. 安装与快速上手

### 在 Windows 上运行
```powershell
# 编译生成原生 PE32+ 二进制程序
.\ykn_full.exe hello.ykn -o hello.exe

# 运行程序
.\hello.exe
```

### 在 Linux (原生或 Docker) 上运行
```bash
# 编译生成原生 Linux ELF64 二进制程序
./ykn_full hello.ykn -o hello
chmod +x hello
./hello
```

## 3. 多语言原生语法系统

在 Yukinary 中，你可以完全使用中文编写清晰的系统级代码：

```ykn
函数 计算总和(值: 整数) -> 整数 {
    变量 结果: 整数 = 值 * 2;
    如果 结果 > 100 那么 {
        返回 结果;
    } 否则 {
        返回 0;
    }
}
```

### 中文关键字对照表:
* `函数` — 声明函数
* `变量` — 声明变量
* `如果` .. `那么` .. `否则` — 条件分支
* `循环` — 循环结构
* `返回` — 返回结果
* `结构体` — 自定义结构体
* `枚举` — 代数数据类型
* `匹配` — 模式匹配
* `空` — 空指针 (Null)

## 5. 函数与流程控制

### 硬件寄存器优化循环
编译器会自动将循环计数器分配到硬件寄存器（`RBX`, `R12`..`R15`）中极速运行：

```ykn
函数 阶乘(n: 整数) -> 整数 {
    变量 积: 整数 = 1;
    变量 i: 整数 = 1;
    循环 i <= n {
        积 = 积 * i;
        i = i + 1;
    }
    返回 积;
}
```

## 7. 带载荷枚举与模式匹配

```ykn
枚举 任务状态 {
    等待中,
    执行中(整数),    # 携带进度百分比
    失败(整数),      # 携带错误代码
    完成(整数)       # 携带返回代码
}

函数 处理状态(s: 任务状态) -> 整数 {
    匹配 s {
        任务状态.等待中 => {
            返回 0;
        }
        任务状态.执行中(进度) => {
            返回 进度;
        }
        任务状态.失败(代码) => {
            返回 0 - 代码;
        }
        任务状态.完成(结果) => {
            返回 结果;
        }
    }
}
```

## 9. 自愈编译引擎 (Self-Healing)

在传入 `--onar` 或 `--self-heal` 标志时：
1. 自动生成备份文件 `.bak`。
2. 纠正语法拼写错误并自动补齐行末分号。
3. 注入动态空指针防护网（Null-Guard）：
   ```ykn
   如果 指针 != 空 那么 {
       返回 指针.值;
   }
   返回 0;
   ```
4. 在作用域闭合前补齐 `返回 0;`。
5. 所有候选修复方案必须经过编译器严格验证，确保修复后可正常运行。

## 11. 沙箱权限门禁 (Sandbox Gate)

在 AST 语法树阶段拦截不受信代码的高危调用：
* 拦截非法套接字网络操作（`socket`, `send`）
* 拦截外部系统进程创建（`CreateProcess`, `execve`）
* 拦截任意动态链接库加载（`LoadLibrary`, `dlopen`）

## 12. 内置神经引擎: Micro-LLM

内置于编译器 `.rodata` 数据段的 **16 KB BitNet 1.58b 三值 Transformer**:
* 零外部依赖，无需 GPU 和 Python，CPU 运行耗时仅 0.1 毫秒。
* 实时提供意图感知代码补全与诊断修补建议。
* 支持通过 `--llm-model model.gguf` 连接外部大规模 GGUF 模型。

## 14. 包管理器与双仓库架构

YKN 社区生态采用清晰的双仓库分离架构：
1. **核心编译器仓库:** `yukinary/yukinary`
2. **包生态分发仓库:** `yukinary/packages`

`yukinary.toml`:
```toml
[package]
name = "my_service"
version = "0.1.0"
main = "main.ykn"
output = "build/app.exe"

[dependencies]
network = "1.0.0"
```

添加包命令：
```powershell
.\ykn_full.exe add network
.\ykn_full.exe build
```

## 15. 多语言转译引擎 (`#convert`) 与外部 FFI 交互

YKN 具有强大的生态兼容能力，解决新兴语言的库生态问题：

### A. 零开销 C-ABI FFI 直接调用 (`harici isv`)
直接调用 C/C++ 或 Rust 编译生成的动态链接库（Windows `.dll`，Linux `.so`）：

```ykn
harici isv sqlite3_open(文件名: *字节, 数据库句柄: **字节) -> 整数;
harici isv sqlite3_close(数据库句柄: *字节) -> 整数;
```

### B. `#convert` 嵌入式转译指令
在 YKN 源码中直接嵌入其它语言的代码，由编译器内置转译器自动转换为纯 YKN 代码：
* `#C-convert` — 将 C/C++ 函数与结构体转译为 YKN
* `#PY-convert` — 将 Python 函数 (`def`) 转译为静态类型的 YKN 函数
* `#JS-convert` — 转译 JavaScript 算法逻辑

### C. 双层 SHA-256 智能缓存 (`.ykn_cache/convert/`)
所有转译后的代码自动按 SHA-256 哈希缓存，二次编译时零开销跳过转译。
